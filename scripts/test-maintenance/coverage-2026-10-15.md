## Added coverage

- Query failures: SQL exceptions, runtime exceptions, and errors preserve the original failure and suppress cleanup failures across scalar, collection, update, callable, and stream APIs; statement ownership is checked in both automatic-close modes.
- DAO reads: checked and unchecked DAOs, selected columns, row filters/mappers, extractors, empty and duplicate results, and cursor pagination across list, map, iterable, iterator, dataset, and scalar results.
- DAO writes: generated and explicit keys, selected columns/custom SQL, named/positional/scalar batch parameters, integer/long update counts, empty inputs, and rollback after later insert, update, or delete chunks fail.
- DAO transactions: all six propagation modes, with and without an outer transaction, successful and failing callbacks, and four logging configurations. Assertions cover connection identity, persisted rows, rollback boundaries, and restoration of caller transaction/logging state.
- DAO validation and binding: 39 invalid declaration cases fail before statement preparation; array/collection bind lists handle values, empty inputs, and null inputs while preserving placeholder order around SQL fragments and scalar parameters.
- Driver conversion and lifecycle: Oracle timestamp/date/timezone values, nanosecond preservation, conversion failures, close-handler ordering, asynchronous failure/cancellation cleanup, and national-character binding.

## Why 100% remains unmet

Some missed branches are unreachable through the supported API in this build:

- [`SqlIdentifierUtil`](../../src/main/java/com/landawn/abacus/jdbc/SqlIdentifierUtil.java) fixes `IDENTIFIER_QUOTING_ENABLED` to `false` and deliberately retains quoting-enabled branches. The corresponding quoting fallback in `JdbcUtil.dropTableIfExists` is also disabled.
- [`DaoImpl`](../../src/main/java/com/landawn/abacus/jdbc/DaoImpl.java) rejects `RowMapper`/`ResultExtractor` parameters on annotated `@Query` methods before building their query functions. Retained mapper/filter dispatch branches cannot run through DAO creation.
- [`NamedQuery`](../../src/main/java/com/landawn/abacus/jdbc/NamedQuery.java) validates stream parameter names and initializes the name-index map in `isRepeatedParameter` before entering setters. Several later missing-name checks and map-initialization branches are therefore redundant.

Other gaps remain testable and should not be confused with these unreachable paths. The largest remaining source totals are:

| Source | Uncovered lines | Uncovered branches |
| --- | ---: | ---: |
| DaoImpl.java | 485 | 1218 |
| JdbcUtil.java | 410 | 402 |
| JdbcCodeGenerationUtil.java | 61 | 221 |
| NamedQuery.java | 58 | 91 |
| Jdbc.java | 37 | 103 |

Further work should prioritize remaining join/caching/handler DAO paths, JDBC preparation/metadata/error adapters, code-generation boundary conditions, and vendor-specific behavior. Legacy JDK/linkage fallbacks need compatible runtime environments; the external MySQL suite needs its documented database configuration. Reaching a literal 100% would also require an explicit decision about retained unreachable production branches. This change does not alter production policy or exclude code to raise the percentage.

node scripts/test-maintenance.mjs --check --json target/test-inventory.json
